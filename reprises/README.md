# Points de reprise

À utiliser **seulement** si vous êtes bloqué et que l'atelier suivant commence :
copiez le fichier dans `src/` (ou `src/legacy/`), relancez les tests, et notez dans
`JOURNAL.md` ce qui a coincé. Lire un point de reprise **avant** d'avoir essayé
vous prive de l'exercice : la formation, c'est le chemin, pas le fichier.

| Dossier | Remplace | Pour démarrer |
|---|---|---|
| `fin-atelier-04/` | `src/tickets.js` | l'Atelier 5 |
| `fin-atelier-05/` | `src/backlog.js`, `src/api.js` | l'Atelier 6 |
| `fin-atelier-06/` | `src/kanban.js`, `src/legacy/kanban-legacy.js` | l'Atelier 7 |
